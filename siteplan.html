Website Site Plan Final Project

Course:WDD 230 - Web Frontend Development

1. Site Name

Name: Puzzle Switch

Optional Domain Availability: puzzleswitch.org

Reason for Selection:

The name explains the reason for the site for the community where people can exchange pre-owned puzzles

2. Site Purpose

The purpose of the Puzzle exchange site is to provide a place where puzzle enthusiast can come together to exchange puzzles that they have completed with others so that jigsaw puzzle making is more cost effective by swapping, logging an inventory, and provide basic shipping information.

3. Scenarios for target audience

Questions that the site answers for the target audience of puzzle hobbyists

  • Can I filter available puzzles by piece count(i.e. 500 or 3000), forms(i.e. 2D or 3D), and cut(i.e.Ribbon or Grid)?
  • Shipping calculator or local drop-off option to manage exchange?

4. Color Scheme

  • Primary Color (#013328) Dark Emerald Green: Headings, navigation bar background, and buttons
  • Accent Color (#F8Cf7C) Light Amber: Call-to-action buttons, links
  • Background Color (#E3DCD2) Greige: Main Background color
  • Text Color (#100C0D) Black: Used for Text for easy readablility

5. Typography

  • Heading Font: Helvetica/Arial/sans-serif
  • Body Font: Georgia/Times New Roman/sans-serif
